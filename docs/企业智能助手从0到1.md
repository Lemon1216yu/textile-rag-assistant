# 纺织知识助手：工程流程

## 资料接入
维护人员上传文档，指定版本、部门和面料编号。后台任务校验原文件，提取文字、按页和章节切分，并记录切片设置。文字不足的 PDF 进入失败队列，需先完成 OCR 或处理空页。

## 离线索引
标题、章节和正文一起进行向量编码。切片、来源和向量保存到数据库，配置 Milvus 时写入对应集合；分词文本用于构建持久化 BM25 索引。文档完成索引后进入待审核状态，只有发布后才参与员工检索。

## 在线检索
识别问题类型、补充确认过的上下文；缺少面料条件时澄清。按部门权限和发布状态过滤，执行向量与关键词召回、RRF 融合、MMR 筛选、去重和精排。未找到足够依据时说明限制；有依据时提供摘录或带引用的生成回答。

## 会话与业务边界
最近对话、主题摘要和明确的用户条件用于保持上下文。历史回答不能替代当前证据；文档下架或权限改变时，历史引用也需重新检查。实时经营数据依赖业务系统接入，质量放行与业务承诺转交人工判断。

## 更新与验证
待审核或失败版本可用原文件修改切片设置并重建。已发布资料通过新版本替换。固定问题集比较基线与完整检索，同时验证无答案、权限隔离、版本替换和失败重试。模拟数据和小样本结果不代表生产效果。

详细操作见项目根目录使用说明及《企业版部署与验收》。
