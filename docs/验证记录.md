## 已修正的问题

测试时发现 SQLite 上下文管理器只提交事务但没有主动关闭连接，会导致 Windows 无法清理测试数据库；已改为显式关闭连接。测试目录已限定为 `tests/`，临时文件放在项目 `tmp/`，避免收集下载缓存里的第三方测试或触碰受限系统临时目录。欢迎页初始滚动位置已修正。
